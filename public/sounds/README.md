# Required Audio Files

Drop your `.mp3` files into this folder (`public/sounds/`) with the exact names below. Files that already exist are marked with (✓). Missing files just stay silent until you add them.

## Gameplay (board)

| # | File name | Action |
|---|-----------|--------|
| 1 | `Dice_Roll1.mp3` (✓) | Dice rolled (variant 1) |
| 2 | `Dice_Roll2.mp3` (✓) | Dice rolled (variant 2, picked randomly per roll) |
| 3 | `piece_move.mp3` (✓) | A piece steps on each cell of the track |
| 4 | `release.mp3` | A piece leaves its home base |
| 5 | `capture.mp3` | A piece captures an opponent's piece |
| 6 | `sent_home.mp3` | A captured piece gets sent home |
| 7 | `safe_spot.mp3` | A piece lands on a safe / globe cell |
| 8 | `finish.mp3` (✓) | A piece reaches its home column |
| 9 | `win.mp3` | Victory fanfare — a player wins the game |
| 10 | `penalty.mp3` | Rolling three 6's forfeits the turn |
| 11 | `no_moves.mp3` | Player rolled but has no piece that can move |
| 12 | `turn_change.mp3` | It's now this player's turn |
| 13 | `time_low.mp3` | Turn timer is in its last few seconds |
| 14 | `timeout.mp3` | Turn auto-skipped / AFK timeout |
| 15 | `game_start.mp3` | A game / rematch begins |
| 16 | `piece_select.mp3` | Player clicks a piece to select/move it |
